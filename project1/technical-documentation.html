Project Overview

Testipalvelu (Test Service) is a single-page web application that demonstrates random image selection and dynamic color generation. The application displays a header titled "Testipalvelu" at the top, two buttons centered in the viewport, and an image display area.

Key Features:

  • Display a fixed pool of six locally-bundled, copyright-free nature images.
  • Clicking the first button ("Näytä luontokuva") reveals a random image from the pool.
  • Clicking the second button ("Vaihda väri") changes the page background to a random color.
  • Both behaviors are independent and do not interfere with each other.
Test Status: 24 / 24 tests passing (12 Playwright + 12 Robot Framework) • 96.43% line coverage

  src: string           // Relative path to local SVG asset (e.g., "src/assets/forest.svg")
}

Image Pool

IMAGES: Image[]

Exported from src/images.js. An array of exactly 6 Image objects representing the available pool for random selection.

Example:

export default [
  { id: "forest", name: "Forest Scene", src: "src/assets/forest.svg" },
  { id: "mountain", name: "Mountain Peak", src: "src/assets/mountain.svg" },
  // ... 4 more images
]

Core Functions

pickRandomImage(images: Image[]): Image

Pure function that takes an array of images and returns one element chosen uniformly at random. Throws an error if the array is empty.

Implementation: Uses Math.random() * images.length | 0 to select an index.

pickRandomColor(): string

Pure function that generates and returns a syntactically valid CSS color value. No palette restriction.

Implementation: Returns a random 6-digit hex string, e.g., #a3f2c1.

DOM Elements & Event Wiring

wireUpPage(): void

Called on page load to attach click handlers and initialize the page state.

Wiring:

  • #reveal-button click → call pickRandomImage(IMAGES) → set #image-display img src/alt.
  • #color-button click → call pickRandomColor() → set document.body.style.backgroundColor.

Important: The two handlers are independent. They do not share state and do not call each other.

How to Run the App

Prerequisites

  • Node.js 18+ and npm

Steps

  1. Install dependencies: 
    npm install
  2. Start the development server: 
    npm run serve

    The app will be served at http://localhost:4173.

  3. Open in browser: Navigate to http://localhost:4173.
Note: The app is a static single-page application (no backend required). All functionality (random image selection, color generation) runs in the browser.

How to Run the Test Suite

Prerequisites

  • Node.js 18+ and npm (for Playwright tests)
  • Python 3.8+ and pip (for Robot Framework tests)

Run All Tests (Playwright + Robot + Merge)

The easiest way to run the full suite and merge results is: 

npm install                              # Install Node dependencies
npx playwright install chromium         # Install Chromium browser
npm test                                # Runs npm run test:playwright, then test:robot, then test:merge
Result: test-results.xml will contain all 24 tests (12 Playwright + 12 Robot) merged together.

Run Playwright Tests Only

npm install
npx playwright install chromium
npm run test:playwright

Output: test-results-playwright.xml, test-output/playwright-report.html, and coverage.lcov.

Run Robot Framework Tests Only

Setup Python environment and dependencies: 

# Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate  # On Windows
# source .venv/bin/activate  # On macOS/Linux

# Install dependencies
pip install -r tests/requirements.txt

# Initialize RFBrowser with Chromium
.venv\Scripts\rfbrowser init chromium

Run Robot tests: 

# With .venv\Scripts on PATH:
npm run test:robot

Output: test-results-robot.xml, test-output/robot/report.html, and test-output/robot/log.html.

Merge Test Results

After running both Playwright and Robot suites, merge them into a single JUnit file: 

npm run test:merge

Output: test-results.xml (merged from Playwright and Robot Framework results).
