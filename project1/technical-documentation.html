Overview

Väripalvelu is a single-page static web app. A header titled "Testipalvelu" sits above a centered pair of buttons: the first reveals a new, randomly selected nature illustration on each click; the second changes the page background to a new random color. The two behaviors are independent of each other. The image pool is six original, locally-bundled SVG assets, so the app has no external network dependency and no copyright risk (see REQ-TECH-001).

Data Shapes

type Image = { id: string, name: string, src: string } // src: relative path to a local .svg

IMAGES: Image[] // exactly 6 entries, src/images.js

pickRandomImage(images: Image[]): Image
// returns one element of images chosen via Math.random()
// throws if images is empty

pickRandomColor(): string
// returns a random 6-digit hex color string in the form #rrggbb
// no fixed palette — fully random per channel via Math.random()

wireUpPage(): void
// attaches a click listener to #reveal-button that:
//   1. calls pickRandomImage(IMAGES)
//   2. clears #image-display
//   3. appends a new <img src=image.src alt=image.name>
// attaches an independent click listener to #color-button that:
//   1. calls pickRandomColor()
//   2. sets document.body.style.backgroundColor to the result
